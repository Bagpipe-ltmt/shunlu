# 顺路 · 公交到站 / 路线 / 乘车码

一个纯前端的手机端小应用，把三件事放在一屏里：

| 想干的事 | 数据来源 | 需要 Key 吗 |
| --- | --- | --- |
| 看公交还有几分钟到站、附近站点、公交换乘 | 车来了（chelaile-api-server 协议） | 不需要 |
| 搜地址、驾车 / 骑行 / 步行路线 | 高德开放平台 Web API | 需要（免费） |
| 一键跳「高德导航」 | 高德 URI API | 不需要 |
| 一键打开支付宝乘车码 / 扫一扫 | 支付宝 URL Scheme | 不需要 |

没有构建步骤，没有后端，没有账号。`index.html + app.js + styles.css` 三个文件就是全部。

**在线地址（手机直接打开，可添加到主屏幕）**

- Cloudflare Pages：<https://shunlu.pages.dev>
- GitHub Pages：<https://bagpipe-ltmt.github.io/shunlu/>

真机截图（390×844，上海 71 路实时数据）：`screenshots/1-bus.png`、`2-route.png`、`3-code.png`、`4-me.png`。

## 一、能做什么

**公交**
- 搜线路（公交 / 地铁）、选方向、看整条线的站序与可换乘地铁
- 「附近站点」按距离排序，每条线路直接显示还有几分钟到站
- 把常坐的线路加进「我的站牌」，每 25 秒自动刷新，显示下一辆 / 第 2 辆 / 第 3 辆
- 公交换乘规划（含地铁），给出总耗时、换乘次数、步行距离、每一段坐什么车

**路线**
- 起终点可以从搜索提示里选，也可以用手机定位
- 四种模式：公交（车来了换乘规划）、驾车 / 骑行 / 步行（高德）
- 每个方案都有「高德导航」按钮，点了会拉起高德 App 直接开始导航（拉不起来就落到高德网页版）

**乘车码**
- 一屏直达支付宝乘车码，比在支付宝里翻好几层快得多
- 顺带给了扫一扫和一键添加到桌面

## 二、跑起来

需要 Node.js 18 以上（只为本地起静态服务，应用本身不需要 Node）。

```bash
cd shunlu
node server.js                 # 默认 http://0.0.0.0:8080
PORT=3000 node server.js       # 换端口
PROXY=off node server.js       # 关掉 /proxy 转发
```

启动后终端会打印本机地址和局域网地址，手机连同一个 WiFi 就能打开 `http://电脑IP:8080`。

> ⚠️ **局域网 http 下定位用不了**。浏览器只在 https 或 localhost 下给定位权限，这是安全上下文限制，不是应用的 bug。
> 想在手机上用「附近站点」，用下面任一方式给一个 https 地址：
> - 把 `shunlu/` 整个目录拖到 Vercel / Netlify / Cloudflare Pages（纯静态，一条命令都不用配）
> - 本地开个 https 隧道，例如 `cloudflared tunnel --url http://localhost:8080`
>
> 上传到静态托管时不需要 `server.js`，它只是本地开发用的；`/proxy` 是可选功能（见下文「设置」）。
>
> **优先选 Cloudflare Pages 或 Vercel**：Netlify 免费版新项目会在右下角注入「Powered by Netlify」角标（`197×64`、`position:fixed`、`z-index` 极高），正好压在底部导航右侧，会挡住「乘车码」「我的」两个 Tab 的点击。要关掉它需要升级套餐，所以除非你愿意付费，否则别用 Netlify 免费版。

### 装到手机桌面

用手机浏览器打开 https 地址 → 分享/菜单 → 「添加到主屏幕」。
之后就是全屏应用，长按图标还有「乘车码」「我的站牌」两个快捷入口。离线时外壳能打开（实时数据当然要联网）。

## 三、填设置（都在「我的」页）

### 1. 车来了接口地址

默认 `https://ts-api.tundrey.com`（一个公开托管的 chelaile-api-server 实例，Cloudflare Workers）。
它不属于本项目，可能限流、变更或哪天关掉。要用得稳，可以自己起一个：

```bash
# 按 chelaile-api-server 项目的说明部署（Node 或 Docker），默认监听 8787
# 然后把地址填成 http://你的内网IP:8787 或你的域名
```

自己部署时记得开 CORS（`CORS_ORIGIN=*`），否则浏览器会被拦。
填完点「保存设置」，再点「重新检测」能看到 `chelaile-api v2.x.x` 就算通了。

### 2. 高德 Web 服务 Key（可选）

没有 Key 时：公交到站、公交路线、一键跳高德导航**全部可用**，搜地址会退化成用车来了的关键字搜索（够用但不精确），驾车 / 骑行 / 步行会提示你去填 Key。

想解锁全部功能：

1. 打开 <https://console.amap.com/dev/key/app>，注册并实名（个人开发者免费）
2. 「应用管理 → 创建新应用」，服务平台选 **Web服务**（不是「Web端(JS API)」）
3. 把生成的 Key 填到「我的 → 高德 Web 服务 Key」→ 保存

> Key 存在浏览器 localStorage 里，只在你自己的设备上。想减少暴露，可以在高德控制台给 Key 设 IP / 域名白名单，或者用 `server.js` 的 `/proxy` 把 Key 留在服务端（需要自己改一下前端把 `proxy` 打开）。

## 四、目录

```
shunlu/
├── index.html            页面骨架（四个 Tab：公交 / 路线 / 乘车码 / 我的）
├── styles.css            移动端样式，支持深色模式、底部安全区
├── app.js                全部逻辑（约 1400 行，无依赖）
├── sw.js                 Service Worker：外壳网络优先、离线回缓存
├── manifest.webmanifest  PWA 清单，含两个快捷入口
├── server.js             本地静态服务 + 可选 /proxy（零依赖）
└── icons/
    ├── icon.svg
    ├── icon-192.png
    ├── icon-512.png
    └── icon-maskable-512.png
```

`server.js` 的 `/proxy?url=...` 会转发请求到白名单里的域名（`restapi.amap.com`、`ts-api.tundrey.com`），用来把 Key 藏在服务端或绕开某些网络环境的拦截；默认开启，`PROXY=off` 关掉。

## 五、关于乘车码，先说清楚

支付宝的动态乘车码**没有开放内嵌能力**（每分钟刷新，官方也不打算给第三方渲染）。所以这里做的是「一键直达」：点按钮直接跳到支付宝的乘车码页面。

- Android：`alipays://platformapi/startapp?appId=200011235`
- iOS：同一套 scheme，系统会交给支付宝处理
- 如果手机没装支付宝、或者系统拦了跳转，页面会在 1.6 秒后给出提示和网页版兜底
- 第一次用需要按支付宝引导开通并绑定城市，之后就是免密

这不是偷懒，是唯一合规可行的做法。

## 七、已知限制 / 常见问题

**「附近站点」一直转圈**
多半是 http 访问导致定位被拒。换 https，或在浏览器地址栏手动允许定位。

**公交接口报错 / 空白**
公共实例可能限流或挂了。到「我的 → 重新检测」看一眼；不行就自建一个 chelaile-api-server 换地址。

**点「高德导航」没反应**
手机上没装高德，或者浏览器拦了 scheme。应用会自动回落到高德网页版导航。

**驾车 / 骑行 / 步行提示要 Key**
这三项走的是高德 Web API，必须有 Key；公交路线走的是车来了换乘规划，不需要。

**城市不对**
右上角城市按钮可以换（492 个城市），换完「附近站点」和搜索都跟着变。
